# 音乐分类、歌单与播放列表

0.5.0 起，音乐库提供「歌曲 / 歌手 / 专辑 / 歌单」四种浏览方式。搜索框同时匹配歌曲、歌手、专辑与路径；歌手 / 专辑页先显示分组，点击分组查看歌曲。空标签显示「未知歌手 / 未知专辑」，不同歌手的同名专辑分开显示。目录筛选继续适用于歌曲、歌手和专辑；歌单拥有独立成员，不受当前目录筛选影响。

添加目录 / 歌曲、四种分类、目录或歌单筛选及管理集中在同一工具栏。常规窗口为一行，最小窗口为两行；打开播放选项后若空间较窄，会分为三行以保留可点击的完整控件。

每行左侧可多选；「全选」针对当前列表。「播放所选」以勾选歌曲替换音乐播放列表并从第一首播放，「播放全部」用于未勾选时的当前列表。「加入队列」追加所选歌曲，未勾选时追加当前全部；已在队列中的路径不重复追加，现有播放不中断。视频库也可播放全部 / 全部加入视频队列。

「新建歌单」输入名称后创建；在歌曲、歌手或专辑中点击「加入歌单」，选择目标歌单。歌单页可重命名、删除，并将勾选歌曲移出歌单。删除歌单或成员不删除磁盘文件，也不移除当前队列。「我喜欢」为固定歌单，播放器的爱心按钮收藏 / 取消收藏当前本地音乐；已下载音乐也可使用，临时联网串流不能保存为本地歌单成员。

歌单按原始路径保存到现有 settings.json，复用后台、延迟与原子保存。旧配置自动补默认空「我喜欢」及顺序播放。歌曲从音乐库移除、目录暂时失联时，歌单保留成员；未索引成员以文件名显示，播放失败由原内核报告，可重新挂载目录 / 恢复文件或移出歌单。重命名 / 移动磁盘文件不会自动追踪新路径。

右下角播放列表按钮打开右侧抽屉，音乐、视频各有列表和播放顺序；切换抽屉标签仅浏览列表，点击一项才切换实际播放。抽屉覆盖内容 / 视频，不改变视频 FBO 尺寸。可点击播放、上移 / 下移、移除或清空；清空正在使用的列表会停止播放，清空另一个列表不打断当前媒体。移除正在播放的一项保留当前播放，到结束后不再自动接续；可手动选择下一项。

支持四种顺序：

| 方式 | 结束时 | 上一首 / 下一首 |
| --- | --- | --- |
| 顺序播放 | 下一项；最后一项结束后停止 | 列表相邻项，到边界停止 |
| 列表循环 | 最后一项回到第一项 | 在边界循环 |
| 单曲循环 | 当前媒体回到开头 | 切换列表相邻项 |
| 随机播放 | 从本轮未播放项中随机选择；新一轮避免立即重复 | 下一首随机，上一首沿实际历史返回 |

音乐 / 视频的顺序分别持久化；播放列表是本次会话的临时队列，重启后为空，歌单可重新批量播放。只有 AppController 处理自动下一首，不开启 mpv 的文件循环来与之竞争。随机模式的一轮覆盖当前曲目以外的各项；单项列表可以重复该项。

边界：最多 128 个歌单（含我喜欢）、所有歌单合计 20000 个成员、单队列 20000 项；名称为 1–80 个字符，不允许重复名称 / 控制字符。配置仍受 2MB 上限约束，过大保存失败时保留原文件并提示。音乐库扫描、播放、图片 / 标签读取与持久化继续使用原有有界后台服务。未引入大库数据库、在线歌单同步或无缝播放保证。
