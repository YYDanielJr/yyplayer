# 音乐库、歌单与播放列表

## 浏览和整理音乐

音乐库提供“歌曲 / 歌手 / 专辑 / 歌单”四种浏览方式。搜索框可以查歌曲名、歌手、专辑和路径。歌手、专辑页先显示分组，点击后查看歌曲；不同歌手的同名专辑分开显示。

添加目录、添加歌曲、分类和筛选放在同一工具栏，窗口较窄时自动换行。播放选项和播放列表从右侧滑入，覆盖页面，不会把歌曲列表或视频画面挤小。目录变化后可点击“重扫”；移除目录或歌曲只移除库里的记录，不删除原文件。

勾选每行左侧的复选框可以多选，“全选”针对当前列表：

- **播放所选**：替换音乐播放列表，从第一首所选歌曲开始播放；没有勾选时，“播放全部”播放当前列表。
- **加入队列**：追加所选歌曲；没有勾选时追加当前全部歌曲。已有路径不会重复追加，当前播放不中断。
- **加入歌单**：选择目标歌单，把所选歌曲保存进去。

## 歌单和“我喜欢”

点击“新建歌单”输入名称。歌单页可以重命名、删除歌单或移出成员，这些操作不会删除原文件，也不会改变正在播放的队列。

“我喜欢”是固定歌单，播放器的爱心按钮可以收藏或取消收藏当前本地音乐。下载到本地的音乐也可收藏；临时联网串流不能保存为本地歌单成员。目录筛选不影响歌单成员。

目录暂时失联或歌曲从库中移除时，歌单仍保留成员，未索引的歌曲用文件名显示。恢复文件或重新连接目录后可以重扫；移动、重命名磁盘文件不会自动追踪新路径。

## 播放列表

右下角播放列表按钮打开右侧面板。音乐与视频各有自己的队列和播放顺序，切换面板标签只是浏览，点击其中一项才会切换播放。

可以播放、上移 / 下移、移除或清空队列。移除正在播放的一项会保留当前播放，结束后不再自动接续；可以手动选下一项。清空正在使用的队列会停止播放，清空另一个队列不会打断当前媒体。视频库也支持“播放全部”和“加入队列”。

| 播放顺序 | 当前媒体结束后 | 上一首 / 下一首 |
| --- | --- | --- |
| 顺序播放 | 播放下一项，最后一项结束后停止 | 按列表顺序切换，到边界停止 |
| 列表循环 | 最后一项结束后回到第一项 | 在列表边界循环 |
| 单曲循环 | 从当前媒体开头重播 | 切换到相邻项 |
| 随机播放 | 从本轮未播放项中随机选择 | 下一首随机，上一首沿实际播放历史返回 |

**歌单是保存的收藏列表，播放列表是本次使用的临时队列。** 重启后队列为空，可以从歌单重新批量播放；音乐、视频各自选择的播放顺序会保存。

## 保存、升级和备份

Windows 数据目录是 `%APPDATA%\YYPlayer`；Linux 是 `${XDG_CONFIG_HOME:-$HOME/.config}/YYPlayer`。便携版也使用系统的用户数据目录。

| 文件 | 保存内容 |
| --- | --- |
| `settings.json` | 外观、音频、快捷键和播放顺序等偏好 |
| `settings.library.sqlite3` | 音乐索引、库目录、单独添加的歌曲、歌单和收藏 |
| `settings.videos.json` | 视频索引 |

SQLite 已内置，无需安装数据库。备份时先退出播放器，再备份整个数据目录。恢复备份也应先退出，再放回数据库和配套设置。

0.5.2 起，第一次启动会自动导入旧 JSON 音乐库和歌单，保留旧音乐索引以及 `settings.pre-sqlite.json` 设置备份。之后以 SQLite 数据库为准，不反复导入旧文件。旧备份只代表迁移前的数据，不包含后来编辑的歌单。

数据库损坏、缺失、版本不支持或无法写入时会显示错误，不会自动删除原库。先恢复文件或权限，再点击“重扫”重试。扫描保存失败时，本次使用期间的编辑仍保留，重试不会用旧数据覆盖它。开发时设置 `YYPLAYER_CONFIG` 可使用独立配置，数据库也跟随该配置路径。

## 当前限制

音乐库和单个队列最多 20000 首；最多 128 个歌单（含“我喜欢”），所有歌单合计最多 20000 个成员。歌单名称为 1–80 个字符，不允许重名。应用设置 JSON 限 2MB，旧音乐索引导入限 32MB；歌单成员不占应用设置的容量。

目前没有实时目录监听、数据库分页、全文搜索、在线歌单同步或无缝播放保证。SQLite 的实现和迁移证据见 [ADR 0012](adr/0012-sqlite-music-library.md)与[迁移验收](validation/sqlite-music-library.md)，当前界面与队列回归见 [0.5.4 验收](validation/frontend-0.5.4.md)。
