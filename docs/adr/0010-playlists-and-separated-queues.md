# ADR 0010：本地歌单、音乐分类与独立会话队列

日期：2026-10-12。用户要求在 dev 增强前端，版本目标 0.5.0；验证与平台边界见 [本轮报告](../validation/frontend-0.5.0.md)。

现有音乐库标签包含歌手 / 专辑，但仅支持平面筛选；音视频共用一个 Vec 队列，播放选项中的简单行列表缺少批量管理。沿用 Rust / Slint / libmpv 与 AppController，不引入另一播放引擎、异步 runtime 或数据库。

core 增加版本化 Playlists（固定我喜欢、单调 ID、PathBuf 成员）与 SessionQueue（有界成员、选中位置、随机袋和有限历史）。Settings v1 通过 serde 默认迁移新增歌单及音乐 / 视频独立 PlayOrder。PathBuf 通过现有无损 path_serde 保存；显示字符串不参与身份去重。后台原子保存和 2MB 上限保持。

音乐库 Browser 维护当前分类、分组键、可见原始路径与多选集合；模型只随库 / 分类 / 选择 revision 更新。歌手按修剪后的标签分组；专辑键为歌手 + 专辑，避免同名混合。已有 Song 标签与缩略图服务复用；歌单成员缺失或从库移除时保留路径，当前队列不受歌单编辑影响。新建 / 重命名 / 删除与批量成员操作都在 controller 提交保存，UI 不读目录或媒体。

AppController 保留一个当前播放 SessionQueue 和另一个独立会话队列；切换实际播放时交换，浏览抽屉标签不切换引擎。各队列的顺序独立保存。EOF 只在匹配实际源、非 pending load、首次 Ended 转换时，由控制器推进；循环同一项使用 Seek / Resume，随机历史由 core 管理。移除 / 重排同步选中位置；去除当前项不重载媒体，避免旧 EOF 错误推进。mpv 文件循环保持关闭，避免双重执行方。

播放列表移出播放选项，新增右下角按钮和右侧覆盖抽屉。视频 FBO / GL notifier / prepare_gl / 租约生命周期不变，抽屉不挤压视频尺寸。音乐库新增分类入口、多选及批量工具栏；列头与行共同保留 32px 多选区。搜索历史用固定 Slint 1.17.1 的稳定布局生成自然宽度胶囊，按可用宽度分行；不启用实验 Flexbox 或升级依赖。

队列是会话状态，歌单和播放顺序持久化。该选择保留已有后台保存模型并避免保存临时串流代理地址。联网串流维持单首解析 / 代理生命周期，结束会话后须从搜索结果重新解析；批量歌单针对本地 / 已下载音乐。文件移动追踪、在线歌单、gapless、大库 DB 与跨平台硬件资格仍为后续独立任务。
