# 浮空提示、顶部工具栏与共用播放控件

日期：2026-10-01。范围：Windows 开发预览，沿用 Slint 1.17.1，不新增依赖。

## 实现

- `app.slint` 将状态信息从标题 / 底部占位行移为浮空卡片，4 秒自动消失，可点击 × 提前关闭。文字改变或新的保存 revision 会重新显示和计时；60ms 状态投影不会重新唤醒已关闭的同一次提示。内核信息 / 渲染错误仍可在原信息页 / 错误区域查看。
- 视频全屏下，PlayerBar 覆盖画面底部，3 秒无操作后隐藏。普通窗口 / 最大化 / 音乐页面仍常显。视频区域始终占满全屏可用高度，显示 / 隐藏不改变 FBO 尺寸。打开侧板仍按原逻辑分配宽度。
- 视频顶部工具栏在窗口 / 最大化 / 全屏下均覆盖画面，52px 高、3 秒无操作后隐藏，鼠标 / 触摸 / 按键唤醒。悬停顶部或底部控件、打开选项、按住拖动时保持可见。原顶部占位布局已移除，视频直接从内容区 y=0 开始；窗口模式视频高度为窗口高度减 70px，顶部隐藏不重新分配 FBO。
- PlayerBar 使用三个区域：左侧媒体标题 / 音乐封面收藏，播放按钮组固定 216px 并相对整个窗口居中，右侧倍速 / 音量 / 选项。删除单独速度文字，实际非预设倍速追加到下拉模型并选中，避免自定义长按速度回显为 1x。增量投影仅在倍速选项变化时更新模型。
- `bootstrap.rs` 在现有 Winit 事件过滤器中观察鼠标移动、按下 / 释放、滚轮、触摸和按键，不拦截这些指针事件。鼠标位置按窗口缩放换算为逻辑坐标；顶部和底部使用各自的悬停保护。失焦清理按下状态，离开窗口 / 改变窗口尺寸清理悬停状态。音乐搜索焦点由页面内部回调投影，切换页面清理，仍保护文本编辑。
- 两个 Slint Timer 只在需要等待超时时运行，触发后停止；未增加轮询线程或修改 mpv / OpenGL 状态交接。

## UI 回归

```powershell
cargo run --locked -p yyplayer-app --example ui-feedback --offline
```

`ui-feedback` 使用真实 Slint UI、软件截图和真实计时器，注入 Slint PointerPressed / PointerReleased 来点击关闭按钮和播放按钮。17 个检查点通过：沿用提示 / 全屏隐藏的 12 项，再检查窗口顶部超时、悬停保护、离开后隐藏、视频高度稳定与顶部无空白像素；分别在常规 1240px、最小 1000px 和较宽 1460px 窗口中央点击，均收到 RequestPlayback。全屏阶段视频区域保持 1240 × 900 逻辑像素；有侧板时宽 870，窗口模式高 830；最小 / 较宽窗口视频高 570 / 850。

本地结果与布局图片在 `target/ui-feedback/`，不进入正常播放路径。已人工查看可见 / 隐藏、最小窗口布局截图，浮空卡片、顶部工具栏和窗口中心按钮位置正确，右侧没有重叠。音乐页仍复用同一控件。这是 UI 状态和 Slint 点击检查，不冒充物理鼠标 / 触摸设备或跨屏 DPI 的人工验收；后者仍需要对应设备。
